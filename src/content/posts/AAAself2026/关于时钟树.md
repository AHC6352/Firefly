## 关于时钟树


stm32 内部的时钟树用于为不同模块提供工作频率、控制频率进行功耗管理、控制时钟信号精度等


### 时钟树组成

HSI：内部高速时钟信号源

HSE：外部高速时钟信号源

LSI：内部低速时钟信号源

LSE：外部低速时钟信号源

PLL：锁相环，一种变频器，对频率做乘法运算

AHB：分频器

### AHB总线

APB2 Fmax = :spoiler[72MHz]


## DWT中的CYCCNT计数器

CYCCNT 是 ARM Cortex-M 内核里 DWT（Data Watchpoint and Trace，数据观察点与跟踪单元）自带的一个 32 位向上周期计数器，每经过 1 个 CPU 内核时钟周期，计数值 +1，相当于把内核主频直接当成计时时钟源。属于 Cortex-M 内核调试组件（M3/M4/M7 有，M0/M0+ 没有），不在 STM32 片上外设里，所以不占 TIM、不占中断、不占 DMA

时钟源：= 内核 HCLK（如 F407 跑 168MHz 时，1 计数 = 1/168M ≈ 5.95ns）。

位数与溢出：32 位无符号，从 0 自增到 0xFFFFFFFF 后自动回绕到 0；F407@168MHz 约 25.5 秒溢出一次，用 当前-起始（无符号减法）可自动处理回绕。

使能前不计数：复位后默认不工作，必须手动开三级开关。

### 三个关键寄存器（F407 / Cortex-M4）

| 寄存器 | 地址 | 关键位 | 作用 |
| --- | --- | --- | --- |
| CoreDebug->DEMCR | 0xE000EDFC | bit24 TRCENA | 总开关，置 1 才允许 DWT 工作 |
| DWT->CYCCNT | 0xE0001004 | 32 位 | 周期计数值，可读可写（写 0 清零） |
| DWT->CTRL | 0xE0001000 | bit0 CYCCNTENA | 置 1 启动 CYCCNT 计数 |

### 标准初始化（CMSIS 头文件 core_cm4.h 已定义好宏）：

```c
void DWT_Init(void){
    CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk; // 开跟踪
    DWT->CYCCNT = 0;                                // 清零
    DWT->CTRL  |= DWT_CTRL_CYCCNTENA_Msk;           // 启动计数
}
```

### DWT_CYCCNT 微秒延时函数的标准实现

```c
void delay_us(uint32_t us) {
    uint32_t startTick = DWT->CYCCNT;
    uint32_t delayTicks = us * (SystemCoreClock / 1000000);
    while ((DWT->CYCCNT - startTick) < delayTicks);
}//未加溢出保护
```


## RTC实时时钟

RTC（Real-Time Clock，实时时钟）是 MCU 里专门用来”走时间”的独立硬件模块，和 CPU 主频无关，断电也能继续计时，用来记录”现在是几点几分几秒、哪年哪月哪日”，而不是测代码跑了多久。

RTC 不属于 CPU 通用外设矩阵，而是挂在 Backup Domain（备份域）内的独立时钟/日历子系统，与内核、总线桥、普通 APB 外设时钟域隔离。
供电域：VDD 主电源 + VBAT 备用电源（典型 1.8~3.6V，CR2032 即可）
复位域：不受系统复位（SYSRESETREQ）、看门狗复位影响，仅 Backup Domain Reset 或 POR 清日历
总线访问：通过 APB1 接口被 CPU 访问，但计数逻辑不在 APB 时钟域



### 硬件组成
```
+-----------------------------+
|   Backup Domain (独立供电)   |
|                             |
LSE 32k ──┐                           |
LSI ~32k ──┼─> [RTC Prescaler]        |
HSE/128 ──┘     (7位+15位异步/同步分频)|
              │                       |
              ▼                       |
        [32-bit RTC_SSR/CNT]          |
              │                       |
              ▼                       |
   [Calendar BCD Encoder]──> SSR/CALR/DR/TR
              │
              ├─> Alarm A / Alarm B
              ├─> Wakeup Timer (16-bit)
              ├─> Timestamp (TAMP)
              └─> SSR Sub-second (0.1ms@32k)
```



关键寄存器组：
RTC_TR：时间 BCD（时/分/秒）
RTC_DR：日期 BCD（年/月/日/星期）
RTC_SSR：亚秒寄存器（基于预分频余数，分辨率 1/256 s @32.768k）
RTC_CNT（部分系列）：线性秒计数，便于转 Unix time
RTC_TAMPx： tamper / 时间戳捕获（触地开关可接这里）

### 时钟源与精度模型

| 源 | 频率 | 典型精度 | 温漂 | 工程评价 |
| --- | --- | --- | --- | --- |
| LSE 外部晶振 | 32768 Hz | ±20 ppm | ±0.04 ppm/℃² | 黄金标准，年误差<1分钟 |
| LSI 内部 RC | ~32 kHz | ±5% | 大 | 仅用于"有大概时间" |
| HSE/128 | 168M/128 | 同 HSE | — | 主晶振准但断电即停 |

ppm 换算：
LSE ±20ppm → 每天误差 ±1.7 s，每年 ±10.5 min
可通过 RTC_CALR 做数字校准（每 32s 插入/扣除若干脉冲），把误差压到 ±2 ppm 内

**只有LSE低速外部时钟可以在VDD掉电后继续提供时钟信号**

stm32的RTC上还有简单的闹钟功能，可以往闹钟寄存器上设置一个时间戳，当计数器和闹钟寄存器的时间相等时可以触发对应的闹钟中断


### 备份寄存器
STM32 的 RTC 模块中有一组备份寄存器（Backup Registers），用于在 MCU 断电或复位后保存关键数据。备份寄存器通常与 RTC 一起工作，并且在 VDD 主电源掉电时仍然可以通过 VBAT 供电保持数据。

c8t6中有10个16位备份寄存器可以用来储存数据

### RTC处理
HAL库中自带的RTC处理为了兼容F407与H743等具有独立日期寄存器的芯片，日期与时间分开处理，导致其并未将日期数据记录在RTC计数器中。也就是说该配置下，VDD掉电后，日期会丢失

HAL库默认生成的代码中。每次都会初始化RTC，导致RTC停止一小会，也就是说，每次VDD掉电RTC都会慢一点。
