## 关于时钟树


stm32 内部的时钟树用于为不同模块提供工作频率、控制频率进行功耗管理、控制时钟信号精度等


### 时钟树组成

HSI：内部高速时钟信号源

HSE：外部高速时钟信号源

LSI：内部低速时钟信号源

LSE：外部低速时钟信号源

PLL：锁相环，一种变频器，对频率做乘法运算

AHB：分频器

### AHB总线

APB1 Fmax = spoiler[36MHz]

APB2 Fmax =spoiler[72MHz]


## DWT中的CYCCNT计数器 

CYCCNT​ 是 ARM Cortex-M 内核里 DWT（Data Watchpoint and Trace，数据观察点与跟踪单元）自带的一个 32 位向上周期计数器，每经过 1 个 CPU 内核时钟周期，计数值 +1，相当于把内核主频直接当成计时时钟源。属于 Cortex-M 内核调试组件（M3/M4/M7 有，M0/M0+ 没有），不在 STM32 片上外设里，所以不占 TIM、不占中断、不占 DMA

时钟源：= 内核 HCLK（如 F407 跑 168MHz 时，1 计数 = 1/168M ≈ 5.95ns）。

位数与溢出：32 位无符号，从 0 自增到 0xFFFFFFFF 后自动回绕到 0；F407@168MHz 约 25.5 秒溢出一次，用 当前-起始（无符号减法）可自动处理回绕。

使能前不计数：复位后默认不工作，必须手动开三级开关。

### 三个关键寄存器（F407 / Cortex-M4）

| 寄存器 | 地址 | 关键位 | 作用 |
| --- | --- | --- | --- |
| CoreDebug->DEMCR | 0xE000EDFC | bit24 TRCENA | 总开关，置 1 才允许 DWT 工作 |
| DWT->CYCCNT | 0xE0001004 | 32 位 | 周期计数值，可读可写（写 0 清零） |
| DWT->CTRL | 0xE0001000 | bit0 CYCCNTENA | 置 1 启动 CYCCNT 计数 |

### 标准初始化（CMSIS 头文件 core_cm4.h 已定义好宏）：

```c
void DWT_Init(void){
    CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk; // 开跟踪
    DWT->CYCCNT = 0;                                // 清零
    DWT->CTRL  |= DWT_CTRL_CYCCNTENA_Msk;           // 启动计数
}
```

### DWT_CYCCNT 微秒延时函数​的标准实现 

```c
void delay_us(uint32_t us) {
    uint32_t startTick = DWT->CYCCNT;
    uint32_t delayTicks = us * (SystemCoreClock / 1000000);
    while ((DWT->CYCCNT - startTick) < delayTicks);
}//未加溢出保护
```
